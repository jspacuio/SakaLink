You are a senior full-stack web developer, UI/UX designer, database architect, and software engineer.

Build a fully functional, responsive web application called SAKALINK, based on the provided SAKALINK prototype and user flows.

SAKALINK is an all-in-one agricultural digital marketplace that connects Farmers, Buyers, and Lenders in one platform.

This must be a working web application, not just a static UI prototype. All major buttons, forms, navigation, authentication, CRUD operations, marketplace functions, messaging, orders, and loan management features must work.

1. APPLICATION CONCEPT
Application Name

SAKALINK

Tagline

"Connecting Farmers, Buyers, and Lenders."

Main Purpose

SAKALINK solves common agricultural problems by providing one platform where:

Farmers
→ Sell agricultural products
→ Find buyers
→ Manage harvests
→ Apply for agricultural financing

Buyers
→ Discover agricultural products
→ Find nearby farmers
→ Purchase crops
→ Communicate with farmers

Lenders
→ Discover legitimate agricultural projects
→ Review farmer information
→ Evaluate loan applications
→ Approve or reject financing requests
